## Что важно понимать о структуре кода

- Go (`go-platform/`) — приём событий, разбор/резолвинг/корреляция/приоритизация,
  маршрутизация, сценарии, SLA, admin API. Это основной, нагруженный
  тракт — см. `../../CLAUDE.md`, раздел «Кто чем владеет».
- Python — тонкий TrueConf-адаптер (`services/delivery_trueconf/`,
  обязательно, т.к. нет открытого Go SDK под TrueConf) + миграции +
  синтетическое демо. Не бизнес-логика.
- React/TypeScript (`web/`) — консоль администратора, адаптирует
  интерфейс под уже вычисленные backend'ом permissions/данные, сама не
  принимает решений (см. `../../CLAUDE.md`, раздел CODE QUALITY RULES).
