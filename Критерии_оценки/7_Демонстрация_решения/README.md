# 7. Демонстрация решения

Вес критерия — 0.10. Продукт готов на 5/5, риск — только в сценарии
показа (не в готовности функциональности). Полное обоснование —
`../../alert-platform/COMPLIANCE_MATRIX.md`, раздел 7.

| Требование планки | Покрывается | Пробел |
|---|---|---|
| Последовательна и интерактивна | Один непрерывный поток (см. Приложение А в `PRESENTATION_CONTENT.md`) | нет |
| Self-service изменение подписки «на лету» | Личный кабинет → сразу событие того же потока → маршрутизация новому подписчику | нет |
| Корректная маршрутизация | Группа + зона ответственности CMDB + SLA-каскад | нет |
| Полный цикл (спецификация §19.1, для полноты) | Шаги 1–4, 6–9 реализованы и проверены живьём; шаг 5 (`следствие`-обучение правилу через диалог) — нет | **Честный пробел**: развитая семантика команд `взял`/`не мой`/`следствие` как маршрутизирующих команд бота — следующий этап, явно так написано в `CLAUDE.md`, не приписывается готовым |
